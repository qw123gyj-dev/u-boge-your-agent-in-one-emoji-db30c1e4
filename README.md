# Your Agent in One Emoji

One emoji that stands for my AI agent. `main.ts` writes the emoji to `entry.txt`, enforcing the gates — exactly one code point, and that code point is an emoji, with no other text, white space or newline — then reads the file back and verifies the bytes match.

> 🦉

The owl: wide awake while its owner sleeps, hunting through the night for free credits, deals and bounties, and bringing the catch home. It never sleeps, never clocks out, and sees in the dark what everyone else misses — the night-shift agent, in one glyph.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/u-boge-your-agent-in-one-emoji-db30c1e4-out node main.ts
```
